# Dependencies for scripts/split_audio_stems.py (GPU stem separation).
#
# Nothing here needs installing for normal use: the script carries a PEP 723
# header, so `uv run scripts/split_audio_stems.py` builds this environment on
# its own, on any platform. This file is for a conventional venv/pip workflow,
# and as a record of the exact versions verified working on this machine.
#
#   uv pip install -r requirements.txt
#
# The three torch wheels are pinned by URL rather than via --extra-index-url.
# An extra index would make uv resolve *every* package against PyTorch's index
# first, so certifi and friends fail to be found there at the pinned versions;
# the workaround is a global --index-strategy flag, which is not expressible in
# a requirements file. Naming the wheels directly keeps the plain command
# working, since then everything else simply comes from PyPI.
#
# The cost is that those three lines are specific to CPython 3.13 on 64-bit
# Windows, and the CUDA build must carry sm_120 kernels for the RTX 5070 --
# torch without them fails at the first GPU dispatch, not at import. For a
# different interpreter, OS or card, swap the filenames from
# https://download.pytorch.org/whl/cu128/ or just use `uv run`, which works
# all of this out per-platform on its own.
#
# --pre is for onnx-weekly, which audio-separator pulls in as a pre-release.
#
# Regenerate the pinned versions with:
#   uv export --script scripts/split_audio_stems.py --no-hashes
--pre
